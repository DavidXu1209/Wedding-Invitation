# assets — 静态资源目录

婚礼邀请函所需的图片与纹理资源，路径在 `js/config.js` 中引用。

## 目录说明

### `photos/`

婚礼照片，用于页面相册与轮播展示。

- 格式：JPEG / WebP
- 单张建议 < 500KB（展示用）
- 按分组管理（如：相识、求婚、婚纱照）
- 文件名建议使用有意义的英文或拼音，避免空格与特殊字符

### `share/`

微信及社交平台分享用图片。

- 用途：Open Graph 缩略图、微信分享预览
- 建议尺寸：≥ 300×300 px
- 建议体积：< 32KB（微信分享优化）
- 在 `config.js` 的 `share.image` 中配置路径

### `textures/`

页面背景与装饰纹理。

- 用途：封面背景、纸质纹理、轻量装饰层
- 格式：WebP / PNG（需透明时使用 PNG）
- 体积尽量小，避免影响首屏加载
- 在 `config.js` 的 `textures` 中配置路径

## 使用方式

1. 将资源放入对应子目录
2. 在 `js/config.js` 中填写相对路径（如 `assets/photos/01.jpg`）
3. 页面逻辑从 `CONFIG` 读取，不在 HTML 中硬编码
