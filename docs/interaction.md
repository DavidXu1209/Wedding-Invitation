# 交互规范

视觉方向：法式复古（French Vintage / Châteaux Style）· 经典庄园 · 高级克制

## 浏览模式

- 单页纵向 scroll
- 无底部 Tab 导航
- Cover 点击「开启请柬」后进入后续章节
- 375px 基准，微信内置浏览器优先

## 动效原则

**克制：** fade + translate，单次 ≤ 800ms

**禁止：** 爆炸、弹跳、粒子雨、金色特效、翻牌倒计时

**无障碍：** 尊重 `prefers-reduced-motion`，跳过动画直接切换

## Cover · 序章·叩门

| 项 | 规范 |
|----|------|
| 触发 | 点击「开启请柬」或底部热区 |
| 反馈 | Cover fade + translateY |
| 结果 | smooth scroll 至 Couple 章节 |
| 时长 | 500ms 延迟 + 800ms 过渡 |
| 样式 | 纯文字链，无按钮、无箭头装饰 |

## Wedding Details · 导航

| 项 | 规范 |
|----|------|
| 形式 | 「导航」文字链，无地图卡片 |
| 微信 | 优先调起高德 App |
| 降级 | App 失败时跳转高德 H5 |
| 样式 | `--color-hairline` 下划线；点击变 Champagne Gold 或 Burgundy |

## Wedding Details · 倒计时

| 项 | 规范 |
|----|------|
| 形式 | 衬线体装饰感数字，如「距婚礼还有 · 58 · 天」 |
| 更新 | 每日递减，无秒级跳动 |
| 禁止 | 翻牌、滚动数字、色块卡片 |

## Gallery · 相册

| 项 | 规范 |
|----|------|
| 浏览 | 纵向 scroll，大图依次展示 |

## Guest Notes · 来宾寄语

### 气质

**高级法式签名册** — 非弹幕、非评论区、非社交 App

连续纸面，姓名与祝福如手写笔迹依次排列。

### 展示

| 项 | 规范 |
|----|------|
| 排列 | 纵向单列，条目间距 40px |
| 形式 | 无边框、无色条；姓名一行 + 祝福一行 |
| 禁止 | 卡片列表、横向飞行、气泡、彩色背景、实时刷屏 |

### 提交

| 项 | 规范 |
|----|------|
| 字段 | 姓名（≤12 字）+ 祝福（≤100 字） |
| 样式 | 手写栏式底线输入，非矩形输入框 |
| 提交 | 「留下祝福」文字链 |
| 动效 | 提交后 fade-in ≤ 600ms + translateY 8px |
| 空状态 | 「成为第一位祝福的新人吧。」不显示假留言示例 |

### 审核

- 默认预留审核机制（`config.guestNotes.moderation`）
- 展示逻辑与后端实现阶段决定
- 当前暂不实现后端

## 全局 CTA 规范

所有可点击入口统一为**文字链**形式：

- 无背景色按钮块
- 无圆角大按钮
- 无阴影 CTA
- 细线下划线指示
- 点击改变 opacity 或下划线颜色（点缀色）

## 安全区域

- 使用 `env(safe-area-inset-top/bottom)`
- 刘海与底部 Home 条不遮挡文字与 CTA
