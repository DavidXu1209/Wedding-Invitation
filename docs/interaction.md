# 交互规范

视觉方向：法式复古（French Vintage / Châteaux Style）· 经典庄园 · 高级克制

## 浏览模式

- 单页纵向 scroll
- 无底部 Tab 导航
- Cover 点击「开启请柬」后进入后续章节
- 375px 基准，微信内置浏览器优先

## 动效原则

**克制：** fade + translate，单次 ≤ 800ms

**禁止：** 爆炸、弹跳、粒子雨、金色特效、翻牌倒计时

**无障碍：** 尊重 `prefers-reduced-motion`，跳过动画直接切换

## Cover · 序章·叩门

| 项 | 规范 |
|----|------|
| 触发 | 点击「开启请柬」或底部热区 |
| 反馈 | Cover fade + translateY |
| 结果 | smooth scroll 至 Couple 章节 |
| 时长 | 500ms 延迟 + 800ms 过渡 |
| 样式 | 纯文字链，无按钮、无箭头装饰 |

## Guest Notes · 来宾寄语

### 气质

来宾祝福以弹幕展示，格式为「祝福 - 姓名」。所有访客共享祝福；长按弹幕并输入管理员密码即可删除。

### 展示

| 项 | 规范 |
|----|------|
| 排列 | 四条轻量横向轨道，低频循环展示 |
| 形式 | 祝福内容在前，姓名在后，使用「 - 」分隔 |
| 权限 | 访客可提交和查看；输入共享管理员密码后可删除 |

### 提交

| 项 | 规范 |
|----|------|
| 字段 | 姓名（≤12 字）+ 祝福（≤36 字） |
| 提交 | 「送上祝福」按钮；发送成功后所有访客可见 |
| 空状态 | 显示简洁的无祝福提示，不显示假留言示例 |

### 管理

- 新祝福不经过审核，直接公开显示
- 删除前弹出“请输入管理员密码”
- 由 Supabase 数据库函数校验密码并删除；网页不保存管理员密码

## 全局 CTA 规范

所有可点击入口统一为**文字链**形式：

- 无背景色按钮块
- 无圆角大按钮
- 无阴影 CTA
- 细线下划线指示
- 点击改变 opacity 或下划线颜色（点缀色）

## 安全区域

- 使用 `env(safe-area-inset-top/bottom)`
- 刘海与底部 Home 条不遮挡文字与 CTA
