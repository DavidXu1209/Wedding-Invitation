# 产品定位

## 项目名称

《许超 & 程昱 数字婚礼邀请函》

## 定位

面向亲友分享的移动端电子婚礼请柬，微信内置浏览器优先。单页纵向 scroll，杂志式叙事体验。

## 视觉方向

法式复古（French Vintage / Châteaux Style）· 经典庄园 · 高级克制

## 页面结构

| 序号 | 页面 | 说明 |
|------|------|------|
| 01 | Cover | 序章·叩门，封面主视觉 |
| 02 | Couple | 新人介绍 |
| 03 | Wedding Details | 日期、倒计时、酒店、地址、高德导航 |
| 04 | Our Story | 爱情时间线 |
| 05 | Gallery | 婚纱相册 |
| 06 | Guest Notes | 来宾祝福弹幕（访客共享，管理员可删除） |
| 07 | Share Poster | 分享海报 + 微信分享素材 |

## 核心功能

- 新人信息与婚礼详情
- 婚礼倒计时（杂志装饰感）
- 高德导航（微信 App 优先，H5 降级）
- 爱情时间线
- 婚纱照片 Gallery
- Guest Notes 共享祝福（即时显示，管理员可删除）
- 微信分享优化

## 技术约束

- 纯 HTML / CSS / 原生 JavaScript
- 无构建工具，可静态托管
- 内容集中在 `js/config.js`
